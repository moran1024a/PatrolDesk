# PatrolDesk

把巡检车导出的 CSV 整理成一份简报，汇总设备运行情况，并列出需要回看的失败、取消记录。适合小批量巡检记录的本地归档。

项目使用 Python 3.11 及以上版本。四天、四台设备的示例记录随题目附件提供；数据与依赖准备完成后，运行时无需联网。

## 安装依赖

在准备好的 Python 环境中，进入项目根目录执行：

```bash
python -m pip install -r requirements.txt
```

| 依赖 | 版本 | 用途 |
|---|---|---|
| Rich | 14.2.0 | 终端状态信息和设备概况表 |
| tabulate | 0.9.0 | Markdown 报告表格 |
| wcwidth | 0.2.13 | 表格中中文字符的显示宽度 |

完整依赖及固定版本见 `requirements.txt`，其中也包含 Rich 所需的间接依赖。

## 准备数据

从题目附件的 `data/` 目录取得以下文件：

```text
patrol_2026-09-21.csv
patrol_2026-09-22.csv
patrol_2026-09-23.csv
patrol_2026-09-24.csv
```

可以在项目根目录创建 `data/` 并将四份 CSV 放入其中，也可以修改 `config.toml` 的 `[paths].input_dir`，指向附件所在目录。支持绝对路径和相对路径；相对路径以配置文件所在目录为准，Windows 路径可使用 `/` 分隔。

CSV 应直接位于指定目录下，并保持原始文件名和内容。默认的 `data/` 已加入 Git 忽略规则，原始数据不提交到 PR。

## 使用

在项目根目录运行：

```bash
python main.py
```

默认配置为根目录的 `config.toml`。可以复制配置用于其他批次，通过 `python main.py --config <配置文件路径>` 指定。配置中的相对路径以配置文件所在目录为准。

`[report]` 设置场地和批次名称，`[paths]` 设置输入目录、输出目录及报告模板，`[robots]` 是设备编号与显示名称的对应表。只读取输入目录下的 `.csv` 文件，不递归读取子目录。

默认输出到 `output/`：

| 文件 | 内容 |
|---|---|
| `report.md` | 可直接阅读的巡检简报，包含失败和取消记录 |
| `devices.csv` | 按设备汇总 |
| `daily.csv` | 按日期汇总 |
| `summary.json` | 完整统计结果、来源记录数及校验码 |

重复运行会替换同名产物。校验码也会显示在终端中，可用来核对同一批数据的导出结果。

## 输入记录

CSV 使用 UTF-8 编码，兼容带 BOM 的文件；表头如下，列顺序可以调整。

| 字段 | 含义 |
|---|---|
| `record_id` | 巡检任务唯一编号 |
| `robot_id` | 配置中登记的设备编号 |
| `started_at` | 开始时间，格式 `YYYY-MM-DD HH:MM:SS`，使用场地本地时间 |
| `area` | 巡检区域 |
| `status` | `success`、`failed` 或 `cancelled` |
| `duration_s` | 耗时，非负整数，单位秒 |
| `distance_m` | 行驶里程，非负整数，单位米 |
| `note` | 备注，可为空 |

设备补传记录可能重复。按 `record_id` 去重，内容一致时保留一次；相同编号内容不一致时停止处理。字段缺失、未知设备、无效状态或数值也会停止处理，并给出来源位置。空行忽略。

## 统计口径

- 全部日期均参与统计，按开始日期分组，边界日期包含在内。
- 成功、失败、取消均计入任务总数；合法的零耗时记录保留。
- 成功率为成功任务数除以任务总数，按百分数表示；平均耗时使用全部任务计算。
- 总耗时和总里程直接累加输入值。小数结果保留两位，按四舍五入处理。
- 配置中没有记录的设备也显示，计数为零；每日汇总只列出有记录的日期。
- 设备按编号、日期按先后排序，待关注记录按开始时间及任务编号排序。

`summary.json` 中百分数及平均值以两位小数字符串保存。校验码为 `PD-` 加 SHA-256 摘要前 16 位大写十六进制：对移除 `verification_code` 字段后的 JSON 按键排序，以紧凑格式和 UTF-8 编码计算，保留中文字符。运行时间和本机绝对路径不参与计算。

## 检查导出文件

```bash
python check_report.py
```

输出到其他目录时执行 `python check_report.py <输出目录>`。该命令检查各汇总文件的数量合计、CSV 与 JSON 的一致性及校验码。统计口径和原始数据仍需结合报告核对。

代码入口是 `main.py`，配置在 `settings.py` 中处理；`records.py` 读取记录，`summary.py` 汇总，`reporting.py` 负责导出。Markdown 的版式放在 `templates/daily_report.md`。
